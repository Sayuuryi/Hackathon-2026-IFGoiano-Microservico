Vamos conferir os caminhos?

Esta página verifica a instalação aberta neste endereço. Cada atividade responde por conta própria. Nenhuma conta é criada e nenhum dado pessoal é lido.

Como conferir no Docker 
docker compose ps -a
docker compose --profile audit run --rm verify node docker-diagnostics.mjs

“Up” indica um processo iniciado. A atividade só abre quando sua API e seu banco conseguem responder. O relatório identifica também uma versão antiga de API ou frontend.

Para testar só o parque: docker compose stop park-service. Para reabrir: docker compose start park-service. Cozinha: cooking-service. Lago: fishing-service.
